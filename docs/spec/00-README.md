# ClipNest 新版设计与实施总规划

规划日期：2026-10-03。现状与组件性能基线采集于 2026-10-02。本文件是实施入口；范围是全球个人用户，桌面 + 手机 + Web，后续扩展团队。此任务包是规格与规划，不是已实现或已上线的应用。

## 1. 已固定的决策

1. **先修当前 Electron 的慢路径，再构建 v2。** 当前秒级延迟来自反复启动 PowerShell / Add-Type，而不是已证明的 Electron 框架性能极限。L0 不改历史格式和云协议，只改原生调用、交互与关键路径。
2. **v2 桌面目标为 Tauri 2 + Rust + React。** T11 必须通过 Windows 原型 gate；若不通过，停止迁移，保留 Electron + 相同 Rust 核心。执行模型不得自行改成 Flutter、微服务或其他框架。
3. **手机采用 React Native + Expo development build；Web 采用 React + Vite PWA。** 手机和 Web 是主动收集、检索、整理与复制入口，不承诺全天候读取系统剪贴板。
4. **本地优先、云同步默认关闭。** 无账号可以用本机历史与收藏。私人自动历史不会因加入团队自动共享。
5. **长期收藏与自动历史分别管理。** 缓存驱逐、账号保留期和用户删除有不同操作；清理缓存不能生成云删除。
6. **后端是 Fastify 模块化单体 + PostgreSQL + 私有 S3。** worker 同仓库部署，复用 pg-boss；首发单主写区域，不做多主数据库、全量快照覆盖同步或无上限对象存储。
7. **个人云采用客户端加密。** 身份认证 token 与数据密钥分离；全文检索在客户端。加密互操作、恢复与同步 gate 未通过时，云同步开关保持关闭。
8. **所有资源有预算。** 唯一默认配置见 [limits.v1.json](limits.v1.json)。这里的试用/Pro 容量是测试权益候选，不是正式售价或销售承诺。

## 5. 时间与资源估算

以 3 名开发、含 Rust/Windows 与移动经验，另有设计/测试支持为假设：M0 约 1 周；M1 约 3—5 周；M2 约 5—7 周；M3 约 3—5 周；M4 约 3—5 周。部分工作可并行，总体建议预留 **16—24 周**，加密、商店审核、签名和平台差异可能增加等待。

单人推进建议按“L0 → Windows 本地 v2 → Web 云闭环 → 一个手机端 → 另一手机端 → macOS → 商业版”交付，预留 6—12 个月。估算不替代 T00 后的团队排期；采用低模型不意味着原生焦点、恢复与跨端集成会自动缩短。

可并行：产品组件与本地仓储、schema/fixture 与平台 PoC、Web fixture 与服务端 API。不可并行写同一协议/迁移文件；加密、同步、附件账本由单一模块负责人统一合并。

## 6. 最小商业闭环

桌面找到一条内容 → 用户主动保存或开启近期同步 → 第二设备登录并解锁 → 手机/Web 找到并复制 → 用户看到明确容量与设备状态 → 可信订阅生效。先验证这个闭环，再增加 OCR、模板、批量粘贴和团队。

首发不做：Linux 完整支持、键盘扩展、文件/PDF 网盘、云端明文搜索、云 AI、MCP、团队共享、组织托管密钥、微服务、多主数据库、自研登录/支付。

## 7. 当前基线与验收目标

本机组件基准：前台窗口捕获 helper 中位 1628.295ms；粘贴类仅启动/编译中位 1304.160ms；正常路径固定等待 280ms。选择后约 3.2s 是组件预算相加，未测端到端。见 [定位报告](latency-diagnosis.md)。

目标：预热后快捷键到列表可操作 P95 <100ms；普通文本选择到输入提交 P95 <150ms；1万条合成文本搜索首屏 P95 <100ms；剪贴板图片未变化时重编码次数为 0。**全部是待实现验收目标。** 容量、焦点失败和权限降级不能为了指标被隐藏。

## 8. 决策与变更规则

T00/T06 固定 ADR、候选版本、契约与默认限额。后续任务不得自行更换栈、修改加密封装、增加云字段、改变删除语义或扩大上限。确有矛盾时输出：冲突位置、最小调整建议、受影响任务和新增验收；由模块负责人先更新规格再继续。

每个任务结束提交结果与证据。若 Git 提交，使用中文日志，例如 `修复：移除唤醒路径PowerShell同步启动，增加目标校验与取消`。没有实际运行的检查标为未运行，不把截图或 mock 当平台真机验收。
