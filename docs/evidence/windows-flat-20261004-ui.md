# Windows 扁平界面调整（2026-10-04）

## 实现范围

- 根据用户截图的横向面板结构调整，使用淡紫灰背景、青色文本/链接标题区、橙色图片标题区。
- 顶部搜索、历史/常用/类型过滤、监听、清理、设置与关闭合并为 52 px 的单行工具栏；较窄窗口允许分类横向滚动。
- 卡片固定为 220 × 232 px，卡片间距 16 px；虚拟列表的 JavaScript 估算值与 CSS 尺寸保持一致。
- 去除外壳、卡片与设置页的阴影和渐变，使用小圆角和细边框；悬停、选中时卡片不位移，选中轮廓向内绘制。
- 内容预览调整为 14 px 字号，最多显示六行，图片按比例完整显示；保留常用编辑、保护、删除与所有已有分类功能。
- 彩色标题区采用深色文字提升可读性，键盘焦点有明确轮廓，卡片动作在内部按钮获得焦点时可见。
- 替换原来的三色窗口装饰为 Windows 常见的关闭按钮，仍调用原有关闭面板操作。
- 底部提示改为“粘贴到原输入位置”，以匹配本次目标行为；未改动点击、键盘粘贴、IPC 或主进程逻辑。

## 验证

- `pnpm exec tsc --noEmit -p tsconfig.renderer.json` 通过。
- 静态复核确认 CSS 不包含 `box-shadow`、渐变或卡片悬停位移。
- 此记录只覆盖界面实现与类型检查。实际 Windows 窗口、点击粘贴和安装后的验收由主流程继续执行，尚不能据此记为通过。

## 验收注意

- 建议面板内容区域至少容纳 232 px 卡片和 30 px 上下留白；整体最小高度约 316 px。
- 窄窗口中的分类按钮可横向滚动；小于 820 px 时省略辅助记录数量，小于 1000 px 时省略监听与 Ctrl+K 视觉提示，快捷键功能保留。
- 卡片由原来的 205 × 260 px 改为 220 × 232 px，单屏卡片数会略少，但内容字号更大、整体面板更紧凑。
