把剪切板变成
你的第二记忆。

01TEXT

文字，清楚可读

长文、代码、临时笔记都保留原始内容，卡片直接预览，不必反复切换窗口。

02IMAGE

图片，一眼找到

复制过的截图和图片保留缩略图，在视觉卡片流里快速定位，然后原格式粘贴。

03SETTINGS

配置，随心保存

在设置页调整 Windows 开机自启、历史保存位置和最大保存数量；标记为常用的剪切内容跳过自动清理，长列表使用虚拟滚动保持流畅。
